      Connexion Microsoft à configurer

      Mojang exige que chaque launcher utilise sa propre application Azure, validée par Mojang. Une seule fois :

      1. Il faut un annuaire Microsoft Entra. Si le portail n'en propose pas, crée un compte Azure gratuit : une carte bancaire est demandée pour vérifier l'identité, sans aucun prélèvement.
      2. Sur portal.azure.com : Microsoft Entra ID → Inscriptions d'applications → Nouvelle inscription. Types de comptes : « Comptes dans un annuaire organisationnel et comptes Microsoft personnels ». Pas d'URI de redirection.
      3. Authentification → Ajouter une plateforme → « Applications mobiles et de bureau », avec l'URI https://login.microsoftonline.com/common/oauth2/nativeclient.
      4. Toujours dans Authentification, paramètres avancés : « Autoriser les flux de clients publics » = Oui, puis Enregistrer. Aucun secret client n'est nécessaire.
      5. Copie l'« ID d'application (client) » (page Vue d'ensemble) dans Réglages → ID client Azure.
      6. Remplis le formulaire Mojang (aka.ms/mce-reviewappid) avec l'ID client et l'ID de l'annuaire (tenant), tous deux sur la page Vue d'ensemble. Après l'accord, compte jusqu'à 24 h.

      L'accord de Mojang peut être long, voire ne jamais arriver pour un petit projet. En attendant, JOUER ouvre le launcher officiel avec le profil ATTACK Client.
