    Connexion Microsoft à configurer

    Mojang exige que chaque launcher utilise sa propre application Azure, validée par Mojang. Une seule fois :

    1. Il faut un annuaire Microsoft Entra.
    2. Sur portal.azure.com : Microsoft Entra ID → Inscriptions d'applications → Nouvelle inscription.
    3. Authentification → Ajouter une plateforme → « Applications mobiles et de bureau ».
    4. Toujours dans Authentification, paramètres avancés : « Autoriser les flux de clients publics » = Oui.
    5. Copie l'« ID d'application (client) » dans Réglages → ID client Azure.
    6. Remplis le formulaire Mojang (aka.ms/mce-reviewappid).

    L'accord de Mojang peut être long. En attendant, JOUER ouvre le launcher officiel avec le profil ATTACK choisi.
